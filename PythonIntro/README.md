# Introduction to Mu2e Python Analysis

A beginner-friendly guide to the Mu2e Python stack, designed for physicists new to Mu2e with basic Python knowledge.

## What You'll Learn

This tutorial bridges the gap between basic Python knowledge and conducting real Mu2e physics analysis. You'll learn:

- How the Mu2e Python environment is organized
- How to load and explore EventNtuple data
- How to apply selection cuts
- How to create physics plots
- How to structure a complete analysis workflow

## Quick Start

If you want to jump straight into hands-on work, open the companion notebook:

```bash
conda activate ana_v2.4.0
jupyter notebook FirstAnalysis.ipynb
```

## Prerequisites

- Basic Python knowledge (variables, functions, loops)
- Familiarity with Jupyter notebooks
- Access to the Mu2e Python environment (either via conda, pyenv, or EAF)
- Basic understanding of Mu2e physics concepts (tracks, EventNtuple)
